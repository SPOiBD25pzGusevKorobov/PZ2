Чтобы поиграть в игру нужно перейти в файл main.py и запустить программу, перед вами сгенерируется текстовый бой.

Классы для персонажей и структуры боя:

    Character / Human
    Базовый класс для всех игровых персонажей. Хранит имя, уровень, характеристики (HP, MP, сила, ловкость, интеллект), методы основной и специальной атаки, список активных эффектов, инвентарь и методы управления эффектами.

    Warrior, Mage, Healer
    Потомки базового класса персонажа. Каждый реализует свои уникальные методы атаки и использования навыков. Добавляют собственную боевую механику (критический удар, заглушение, лечение и т.д.).

    Boss
    Спецкласс, наследующий персонажа с индивидуальной стратегией (например, агрессивное или защитное поведение).

    Battle
    Класс, реализующий логику боя между командой и боссом. Управляет очередностью ходов, применением действий, эффектов, а также выводит статусы.

Классы эффектов:

    Effect
    Абстрактный базовый класс для всех эффектов (баффы, дебаффы, молчание и т.д.), содержит название, длительность и метод применения.

    Buff, Debuff
    Потомки Effect. Buff увеличивает силу персонажа на время, Debuff уменьшает.

    SilenceEffect
    Эффект "молчания" — запрещает персонажу использовать навыки на несколько ходов.
Классы-миксины (примеси):

    CritMixin
    Добавляет возможность критических атак персонажу.

    LoggerMixin
    Добавляет удобный вывод/логирование действий на экран.

    SilenceMixin
    Добавляет функциональность временного "заглушения" другого персонажа.
